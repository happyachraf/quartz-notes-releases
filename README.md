# Quartz Notes — Windows downloads

[Download the latest Windows x64 release](https://github.com/happyachraf/quartz-notes-releases/releases/latest)

Choose the `Quartz-Setup-...-x64.exe` installer under Assets. Install it once; future published versions appear inside Quartz → Settings → About & updates. A GitHub account is not needed.

## Future updates

Quartz checks shortly after launch and every six hours while open. You can also choose Check for Updates. When a newer release is available, choose Download update, then Restart to Update when ready. Quartz does not automatically restart while you write. Source edits alone are not published app updates.

## Verification

Updates require signed release metadata and matching installer hashes. Windows publisher signing is not configured yet, so Windows may show Unknown publisher or restrict installation under its policy. Do not disable Windows protections to install Quartz.

## Your data

This repository contains app installers, update metadata and release notes only. Source code is maintained privately. Your notes, Google account credentials, Drive vault and encryption keys are not distributed here. Updates preserve the existing application data location.
