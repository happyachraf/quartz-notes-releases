# Quartz Notes — Windows downloads

This repository contains public installers, verified update files and release notes only. Quartz source code is maintained separately.

## Downloads

No installer has been published here yet. The automatic-update setup is being prepared and tested.

Only install versions listed under [Releases](../../releases). An update-enabled Quartz installation will show new published stable versions inside Settings → About & updates.

## Your data

Your notes, Google Drive vault, account credentials and encryption keys do not belong in this repository. Public app downloads do not grant anyone access to your vault.
